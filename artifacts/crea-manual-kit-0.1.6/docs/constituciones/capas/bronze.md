# Contrato Bronze personalizable

Estado: template
Revisión: 1

Completar con el responsable antes de activar. Esta plantilla no prescribe retención,
identificadores o almacenamiento de un cliente.

| Decisión necesaria | Qué precisar y qué evidencia conservar |
| --- | --- |
| Propósito | Fuentes y límite entre captura y transformación; referencia al contrato de origen. |
| Granularidad | Unidad de ingreso y metadatos de captura; ejemplo sintético representativo. |
| Transformaciones permitidas | Conversiones técnicas aceptadas y cambios de negocio prohibidos. |
| Identidad | Identificación de lote/registro y tratamiento de reingresos; criterio verificable. |
| Errores | Rechazo, cuarentena o conservación y responsable; prueba de entradas inválidas. |
| Conservación | Qué se conserva, por qué y quién aprueba excepciones; política real del proyecto. |

Cada decisión adoptada se convierte en una regla con ID estable `PROY-BRONZE-...`, condición,
obligación, fundamento, evidencia, comprobación y excepciones según README. No inferir decisiones
desde esta plantilla ni cambiarla para aprobar una implementación.
