# Contrato Gold personalizable

Estado: template
Revisión: 1

Completar con el responsable antes de activar; no hay KPIs, fórmulas o dimensiones de cliente
predefinidos en el kit genérico.

| Decisión necesaria | Qué precisar y qué evidencia conservar |
| --- | --- |
| Propósito | Consumo de negocio y dueño de cada definición; criterios aprobados. |
| Granularidad | Dimensiones, período y unidad de medida; reconciliación sintética. |
| Transformaciones permitidas | Agregación, joins y cálculos aprobados; conservación de semántica. |
| Identidad | Claves de agregados/objetos y tratamiento de dimensiones desconocidas. |
| Errores | Reconciliaciones fallidas, ausencia de datos y límites de publicación. |
| Conservación | Versiones de indicadores, historia y correcciones según política del proyecto. |

Convertir decisiones en reglas `PROY-GOLD-...` con condición, obligación, fundamento, evidencia,
comprobación y excepciones. Cambiar una fórmula para aprobar un resultado exige decisión de
alcance del responsable, nunca autoaprobación del Developer o Reviewer.
